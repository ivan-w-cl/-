# 上传说明：把新功能放到在线预览网站

给负责网站上传的同事。大约 5 分钟。

## 要传的文件（7 个）

都在本包的 `overlay/` 文件夹里。上传时**保持文件夹结构**，放到网站根目录（就是现在放 `index.html` 的那一层）。

| 文件 | 操作 |
|---|---|
| `index.html` | 替换原文件 |
| `lessons/lesson01/index.html` | 替换原文件 |
| `discussion-moves.js` | 新增 |
| `discussion-layer.js` | 新增 |
| `discussion-layer.css` | 新增 |
| `team-preview-demo.js` | 新增 |
| `lessons/shared/moves-bridge.js` | 新增（`lessons/shared/` 文件夹如果没有，就新建一个） |

其他文件都不用动，也不用重新上传课程视频和配音。

## 上传前

- 先把线上原来的 `index.html` 和 `lessons/lesson01/index.html` 下载下来备份。如果有问题，把这两个文件传回去就能恢复原样；新增的 5 个文件放着也不会影响任何东西。
- 两个 `index.html` 只加了几行引用新文件的代码，具体改了哪里见 `index.html.diff` 和 `lesson01-index.html.diff`。如果线上版本和交接包里的不一样，就只把这几行加进线上版本，不要整个覆盖。

## 上传后检查（2 分钟）

1. 打开 `网站地址/?demo=student`，左下角（手机上在底部上方）出现「演示学生账号 · 示例数据」，并且能看到「今天」页面。
2. 打开 `网站地址/#moves`，能看到 8 个讨论动作的卡片。
3. 打开 `网站地址/lessons/lesson01/index.html?chapter=s04`，播放器下方出现「本节讨论动作：接住别人的话、追问澄清」。
4. 打开 `网站地址/?demo=off`，回到原来的团队预览。

四项都正常就完成了。如果第 1 步还是原来的样子，一般是浏览器缓存：强制刷新一次（Mac：Cmd+Shift+R；Windows：Ctrl+F5），或者换无痕窗口打开。

## 注意

- 演示账号不连接后端，填写的准备卡、复盘只保存在测试人自己的浏览器里，别人看不到，清除浏览器数据后会消失。
- 演示账号只在加了 `?demo=student` 的浏览器标签里生效，不影响其他访客。
