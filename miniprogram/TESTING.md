# 利物浦学生住宿地图 · 微信小程序测试说明

这个包用来测试**微信小程序（中 / 英）**。小程序要连一台服务器（公寓数据以外的东西都从服务器来：手写字体、房型照片、天气、一键进群、专家后台），包里已经带好，在一台电脑上运行就行。

> 现在还是测试版：没有正式 AppID、没有备案域名，所以订阅消息提醒和分享卡片上的小程序码暂时用不了（会自动退回普通二维码），其余功能都可以测。

## 包里有什么

| 文件夹 / 文件 | 是什么 |
|---|---|
| `miniprogram/` | 小程序源码，用微信开发者工具导入这一层 |
| `web-original/consult-server/` | 服务器（Node.js，无需安装依赖） |
| `web-live/` | 网页版，服务器顺便提供手写字体、房型照片和专家后台 |
| `start-demo.cmd` / `start-demo.sh` | 一键启动服务器（Windows 双击 `.cmd`；Mac 在终端运行 `sh start-demo.sh`） |
| `docs/screenshots/` | 小程序截图，可以对照 |

## 一、准备

1. 安装 **Node.js 18 或更新版本**：<https://nodejs.org>（选 LTS）。
2. 安装 **微信开发者工具（稳定版）**：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
3. 电脑和测试手机连**同一个 Wi-Fi**（只用模拟器测可以忽略）。

## 二、启动服务器

双击 `start-demo.cmd`（Mac：终端里进入解压目录，运行 `sh start-demo.sh`）。看到下面两行就成功了，窗口保持打开：

```
Student website:        http://localhost:8765/
Booking expert console: http://localhost:8765/adviser.html  (password: 123456)
```

第一次运行，Windows / Mac 可能弹出防火墙提示，请选择**允许**（不然手机连不上）。

## 三、在开发者工具里打开（模拟器）

1. 打开微信开发者工具 → 「导入」→ 选择 `miniprogram` 文件夹。
2. AppID 选「测试号」或保持游客模式（`touristappid`）都可以。
3. 右上角「详情 → 本地设置」：勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**（项目里已默认关闭校验，确认一下即可）。
4. 点「编译」。左边模拟器里出现手绘地图和「生活选房」开场页就对了。

模拟器上方可以切换机型（iPhone、安卓、iPad），请多切几种看看。

## 四、真机测试（手机）

游客模式只能用模拟器。要在手机上测，需要一个小程序 AppID（总部注册的正式小程序，或者在 <https://mp.weixin.qq.com> 申请一个测试用的），并把测试同事的微信号加为该小程序的「开发者」或「体验成员」。

1. 把小程序的服务器地址改成这台电脑的局域网 IP，并填上 AppID（在解压目录里运行）：

   ```
   node miniprogram/scripts/set-server.cjs --appid 你的AppID
   ```

   它会自动找到本机 IP（比如 `http://192.168.1.20:8765`）。找错了可以手动写：`node miniprogram/scripts/set-server.cjs http://192.168.1.20:8765`。
2. 开发者工具里点「编译」，再点「预览」，用手机微信扫码。
3. 手机上打开后，点右上角「···」→「开发调试」→ 打开调试，再重新进入（打开调试后才不校验域名，才能连上电脑上的服务器）。
4. 手机要和电脑在同一个 Wi-Fi。连不上时：先用手机浏览器打开 `http://电脑IP:8765/`，能看到网页版说明网络通了。

测完想改回模拟器用：`node miniprogram/scripts/set-server.cjs --local`。

## 五、专家后台（测「一键进群」要用）

电脑浏览器打开 <http://localhost:8765/adviser.html>，密码 `123456`。

学生在小程序里点「立即进群」后，专家后台会出现一条新请求（带 LSM-XXXX 咨询编号）。专家上传一张微信群二维码图片（任意二维码截图都行）或者填 WhatsApp 群链接，点发送，小程序里几秒内就会显示群码。

**测群码过期（清单第 14 项）**：微信群二维码默认 7 天有效。测试时先关掉服务器窗口，用约 4 分钟的有效期重新启动：

- Windows：在解压目录打开「命令提示符」，运行 `set WECHAT_QR_DAYS=0.003`，再运行 `start-demo.cmd`
- Mac：`WECHAT_QR_DAYS=0.003 sh start-demo.sh`

## 七、请特别帮忙确认的几点

这几项在模拟器里看不准，必须用真机：

- 地图上和分享卡片上的**手写字体**能不能正常显示（不正常时会变成系统字体，功能不受影响）。
- 微信群二维码**长按识别**能不能直接进群。
- 分享卡片「保存图片」（第一次会请求相册权限）和「分享」是否正常。
- 中低端安卓机上拖动、缩放地图是否流畅。

## 八、现在不能用 / 属正常的情况

- **订阅消息提醒**（专家发群码后微信通知学生）：需要正式 AppID 和订阅消息模板，测试版没有。
- **分享卡片上的小程序码**：需要服务器配置 AppID / AppSecret；现在是普通二维码，扫了打开的是网页版。
- **价格和评价**是 2026 年 10 月 17 日的历史记录，不代表实时空房。
- 测试数据（咨询请求、群码）保存在运行服务器的电脑上：`web-original/consult-server/data/`。
