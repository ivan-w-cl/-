# 三校考情与流程解析 · 说明

## 包里有什么

| 文件 | 内容 |
|---|---|
| `index.html` | 动画播放页（课程动画同款画风：浅色画面、三位同学围坐提问、底部讲解字幕条）。双击即可打开，和课程一样有 播放/暂停、重播本集、进度条、倍速、字幕、减少动态。西浦、港中深可切换江苏版和广东版 |
| `characters.js` `data.js` `explainer.js` | 页面用到的三个脚本：人物骨架（与课程动画相同）、全部文案与数据、按时间轴绘制画面的引擎。要改内容只改 `data.js` |
| `video/` | 5 个版本的 MP4（1920×1080，无声，字幕已烧录在画面里）+ 同名 SRT 字幕文件 |
| `tools/export-mp4.cjs` | 重新导出 MP4：`node tools/export-mp4.cjs xjtlu js`（需要 Node、Playwright 和 ffmpeg） |
| `逐字稿/西浦-逐字稿.md` | 江苏版 + 广东版的全部旁白，以及每个画面上的文字 |
| `逐字稿/港中深-逐字稿.md` | 江苏版 + 广东版 |
| `逐字稿/上悉4+0-逐字稿.md` | 全国版 |
| `tools/make-transcripts.cjs` | 改了 `data.js` 之后，运行 `node tools/make-transcripts.cjs` 重新生成逐字稿（带时间码），保证动画、MP4 和逐字稿一致 |
| `官方简章/` | 本次依据的 2026 年官方简章，由你们提供 |

## 每所学校的 6 集
1. 考什么
2. 怎么报名
3. 成绩怎么算
4. 面试会遇到什么
5. 考前准备什么
6. 接下来怎么练

| 版本 | 时长（1 倍速） |
|---|---|
| 西浦江苏版 | 7 分 37 秒 |
| 西浦广东版 | 7 分 34 秒 |
| 港中深江苏版 | 7 分 09 秒 |
| 港中深广东版 | 7 分 16 秒 |
| 上悉 4+0 | 5 分 34 秒 |

每集开头，三位同学（小林、小周、阿杰，和课程动画是同一套人物）中的一位先提出这一集的问题，然后由「讲解」用图表回答。

网页播放可以调成 1.25、1.5 或 2 倍速。视频是无声的（和课程动画一样），讲解内容以字幕呈现；以后如需配音，可以按 SRT 的时间轴录制。

## 内容依据和原则
- **政策、日期、费用、计分公式、门槛**：全部来自 2026 年官方简章，每一集画面底部都标了依据的是哪份简章。
- **面试准备建议、练习题、准备节奏**：是 esssouth 的建议，页面上已标明。练习题都写了「原创，不是真题」。
- 上一版网页里的「算一算」计算器这一版没有放进视频画面；如需要，可以放在网站页面里。

## 刻意没有写进去的内容（请团队知悉）
1. **历年录取分数线**：几份官方简章里都没有。如果你们有核对过的数据，可以加进第 3 集。
2. **上悉 4+0 各部分权重**：官方简章没有公布。网上流传的「笔试 60% + 面试 40%」找不到官方依据，所以没有用。
3. **港中深入学测试的形式**：简章写的是「另行通知」，所以只讲了已知部分。如果课程团队有确认过的往届形式，可以补进第 4 集，但要注明「往届情况，以当年通知为准」。
4. **西浦面试的具体形式**：简章只写了「面试，评估英语水平、综合素养及综合能力，不考专业知识」，具体形式以当年通知为准。
5. **上悉 4+0 的 2026 年考试日期**：简章写的是「报名时间详见后续官网通知」，所以没有写具体日期。

## 需要团队核对的两处表述
- 西浦第 5 集说「2026 年的简章是 4 月发布的」：依据是官网 PDF 的上传路径（2026/04）和 4 月 20 日开始报名，简章正文里没有写发布日期。
- 每一集都有一句「2027 年简章发布后，我们会第一时间更新」：这是对用户的承诺，需要有人负责落实。

## 重要提醒
西交利物浦大学在简章中声明：学校不组织任何综合评价考试培训，也未授权任何机构、个人以任何形式开展此类考前辅导或培训。因此：
- 每一集结尾和页面底部都写明了「esssouth 是独立的练习工具，与学校无官方合作关系，一切以学校官方信息为准」；
- 对外宣传时请不要暗示与学校有合作，也不要使用学校的标志。

## 2027 年简章发布后怎么更新
1. 打开 `data.js`，按新简章修改日期、比例、门槛等内容，并修改 `SOURCES` 里的简章链接。每一句旁白都是普通中文，直接改就行。
2. 运行 `node tools/make-transcripts.cjs`，重新生成逐字稿。
3. 运行 `sh tools/run-exports.sh`，重新导出 5 个 MP4。
