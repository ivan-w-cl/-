# Curriculum context

The series is planned as ten core lessons, each with an editorial allocation of roughly thirty minutes. Preview/sample extracts are separate. Watch and Practice are two modes of the same lesson, not additional courses.

Current production sequence:

1. L01: understand shared discussion and ways to contribute.
2. L02: develop a view, reason and example with appropriate limits.
3. L03: listen closely, check meaning and respond to the point.
4. L04: disagree constructively and continue examining alternatives.
5. L05: interpret a prompt, prepare useful notes and make a relevant first contribution.
6. L06: explain a specific experience, decisions and bounded results; respond to follow-ups.
7. L07: notice and respond to pauses, overlapping turns, invitations and sidetracks without taking over the discussion.

Earlier curriculum notes used a different order. This handoff follows the current production sequence and supplies a newly proposed complete Lesson07 script. It is whole Lesson 07, not a seventh section of another lesson.

Remaining planned coverage is combining contributions into a shared proposal, transfer to unfamiliar tasks, and a continuous teaching simulation with review. Those detailed scripts are not included here.

## Learning progression

S01 separates observation from interpretation. S02 considers a pause and a focused next question. S03 makes unfinished and overlapping turns visible. S04 invites participation with room to pass or return later. S05 checks a sidetrack against the shared task before redirecting. S06 privately rehearses one small next move. S07 uses a new task where a practical question is relevant and a person explicitly requests thinking time.

This lesson extends L03's listening and L04's constructive responses. It does not promise that a polite line always works, require equal airtime, appoint the learner as leader or diagnose quiet people. Ordinary pauses and accidental overlaps are not failures that always need correction.

The same main prompt provides continuity, while each excerpt resets. Character examples remain brief; formal teaching surfaces explain the distinctions. Final combined-plan construction belongs to a later lesson. This assignment leaves any plan unadopted unless an authored event explicitly establishes otherwise; no such adoption is supplied here.

The current package is entirely English and requests silent animation. Explanation, example dialogue, semantic timing and audio hooks remain separate for the downstream localization and narration pass. Preserve the accepted visual style.
