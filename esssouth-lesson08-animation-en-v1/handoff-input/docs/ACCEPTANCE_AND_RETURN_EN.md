# Acceptance evidence and return

Run tools/validate-authoring.py first. It checks this input's graph, source consistency, anchors, estimates and fingerprints. It does not test your output animation. Write and run tests against the new runtime.

## Per-section checks

- Implement every supplied cue, hold and alternative once where intended. Preserve exact quotes, label ownership, support conditions and open status. No stale earlier lesson title or accessibility label.
- Inspect actual block opening/middle/end, each branch and meaningful transition frames. Check dense text, tags against vector items, clipping ancestors and model bubbles. Do not accept a merely plausible geometry report without inspecting visible output.
- Maintain prompt constraints and snapshot distinctions. S02 tests accurate support, S03 coherent candidates, S05 updates support only after explicit statements, and S06 keeps private rehearsal separate.
- Exercise all choices, Retry, Skip, repeated Continue, branch-local seek, across-gate seek, mode switches, restart and four rates. Practice must wait beyond the corresponding Watch hold. Its end never becomes an inferred learner answer or adopted plan.
- Test retiming, long text, font fallback, keyboard, visible focus, captions and reduced motion. Preserve readable normal-size DOM captions and choices on narrow screens.
- Check 1920x1080, a practical desktop viewport, 390x844, 820x1180 and tablet landscape. State whether these are viewport simulations or physical devices.
- Extract delivered playable archives freshly and test offline without remote fonts/scripts/assets. Rebuild source with documented dependencies/commands and compare relevant artifact hashes.
- Use available Chromium and WebKit, Firefox if available. Report OS and versions. Playwright WebKit is not Safari.app. A silent build cannot demonstrate audible sync or speech recognition.

## Combined-entry checks

All seven entries must point to actual delivered products. Switch sections during playback, pause, choice waiting and model playback. No hidden clock/audio, duplicate listeners, stale response, incorrect progress or false completion may remain. Preserve selected mode/rate when meaningful and keep the new section at its actual initial state. Next is an explicit user action.

## Optional video

If tools are available, export deterministic Watch frames at 1920x1080/30fps. Do not assume a wall-clock screen recording is frame-exact. Video is silent; remove inherited narration/test tones. Export SRT from the same selected Watch route. Inspect decoded encoded frames, first/middle/end, full decode, resolution/fps/duration and stream contents. Do not concatenate alternative branches or freeze at Practice gates in the MP4.

## Return files

For each section: exact source input plus implemented source/assets, compiled data, standalone/offline playable, editable text/slots/anchors/timing/audio hooks, storyboard, transition examples, actual test report, measured silent timeline, change log, dependency commands and SHA manifest. Source and playable ZIPs are individually below 20 MB. Optional verified MP4/SRT may be separate.

Also return the combined entry, chapter metadata, assembly instructions and BUILD_STATUS.json covering all seven sections. State what is built, exported, tested, incomplete and untested. No claims of final voice, real learner performance, AI assessment, site integration or publication belong to this silent animation delivery.
