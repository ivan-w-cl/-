# 线上版网页（干净源码）

来源：https://liverpool-student-map.wy16875.chatgpt.site/ ，2026-10-22 在浏览器里"另存为网页"后还原。

浏览器另存的是页面运行之后的状态（地图、按钮已经画好），直接打开会重复绘制。这里的 `index.html` 按网页原版 `web-original/liverpool-life-map-en/index.html` 的静态骨架重建，换入线上版的脚本、样式和文件，布局与线上版一致。

与另存文件相比，去掉了 ChatGPT 网站自带的"编辑网站"小部件（`/_sites/dispatch-assets/sites-widget.js`），它不属于本页面。

另存时没有一起保存 `sw.js`，这里按网页原版补了一份。

## 真实运行（跨设备）

和 `web-original/consult-server` 一起部署：`SITE_DIR=web-live node web-original/consult-server/server.js`（见那里的 README）。
网页一打开先查 `./api/health`：有服务器就用真实数据（`case-api.js`、`adviser/store-server.js`，后台需要登录）；没有就退回浏览器本地演示（`adviser/store-live.js`），两种模式界面一样。
学生只有一个 **咨询编号**（如 `LSM-7K2Q`），后台按编号、地区、当地时间区分学生，不收集姓名或联系方式。

## 在线版布局之上补充的功能

- **地图动画**：原页面在手机上默认关掉了车、渡轮和海鸥，现在手机上也播放（拖动地图、系统「减少动态」时会停）；`map-life.js` 多加了一群海鸥飞过默西河。
- **利物浦实时天气**（`weather.js` / `weather.css`）：地图上一个小标签显示利物浦当地时间、天气和气温，点开看最高/最低、降雨概率、天黑时间、和北京/新加坡/东京的时差。下雨、下雪、起雾、阴天和夜晚会画在地图上。数据来自 Open-Meteo（免 key），连不上时显示示例天气。注意：Open-Meteo 免费版只限非商业用途，正式商用需要订阅或换成英国气象局（Met Office）的接口。

线上版原有文件只改了 `index.html` 里的几行引用，以及 `home-match.js` 的答题交互（单选题点选后自动进入下一题；两道多选题选满上限或选「都可以」时自动进入下一题，少选可点「下一题」），新功能都在新文件里，不改变原有布局：

| 文件 | 作用 |
|---|---|
| `room-photos.js` / `.css` | 公寓卡片「展开详情」里加「房型与照片」：房型卡片 + 按卧室 / 浴室 / 厨房分组的相册；相册里「咨询这个房型」打开对话框。收起状态下有照片的公寓多一行照片数量提示 |
| `booking-handoff.js` / `.css` | 咨询 = 进群：点「咨询公寓」后对话框里是「立即进群」，不填资料；下面可以先问一个小问题（有没有房、多少钱、多远、包不包账单），AI 助手（演示为规则回答）只按房源资料回答，问到房态 / 合同或聊了两轮就引导进群，问答会一起交给专家。微信群码 7 天过期后学生可一键申请新群码；中文默认微信、英文 / 日文默认 WhatsApp，可一键改。一位学生一个群，再咨询别的公寓会转给同一个群。右下角消息气泡：顾问发来群码或消息时有红点和提示，可拖动，拖到屏幕边缘收成小箭头。原有的对话演示仍在页面里，只是隐藏 |
| `group-pool.js` | 预建群池（备用，默认关闭）：每位学生默认由专家收到邮件后新建群；预建的微信群码 7 天过期，只适合高峰期备用 |
| `panel-drag.js` / `.css` | 来自网页原版：「找公寓」「公寓列表」（电脑端）和「生活选房卡」按标题栏拖动，拖出屏幕边缘收成小箭头，点箭头或往里拖恢复；双击标题栏回到默认位置 |
| `fancy-select.js` / `.css` | 「我的专业」下拉换成手绘风格列表（放在 label 外面，iPhone 上不会再弹出系统滚轮）；原 `<select>` 仍在页面里驱动原有逻辑 |
| `pick-focus.js` | 生活选房结果高亮时，点开一处不在推荐里的公寓，地图上其他公寓恢复不透明；点「查看上次结果」再恢复高亮 |
| `fun-quizzes.js` / `.css` | 留学人格测试（和生活选房同一个模块，交互完全一样：同款答题卡、点选项自动下一题、侧边结果卡 + 地图标出 3 处推荐公寓）：i 人 / e 人室友人格、留学松弛感、留学搭子（可邀请朋友测合拍度）、订房决策人格。每套测完推荐 3 处公寓并能生成分享卡片。入口在生活选房开场页和选房卡底部；链接直达 `?quiz=ie|soft|buddy|booking`（`&duo=类型`） |
| `booking-tools.js` / `.css` + `quote-check.js` + `booking-ready.js` | **订房小工具**（入口：公寓卡片「展开详情」里的「订房小工具」、收起状态下的两个小按钮、生活选房开场页）。**报价核算器**分两页。「拆解一个报价」：学生只填平台报给他的价格（每周价或合同总价，可加平台另外说的返现），用公寓的官方周租和官方优惠一减，算出平台自己补了多少（大多是私下给的返现），提醒这部分不是公寓降价、通常入住后才到账、没到账时实际要付多少；比官方价还高时提示核对房型和周数；可一键加入比较（不够两个报价时自动加「公寓官网直订」作对照）。官方价和官方优惠由订房专家维护在 `quote-check.js` 的 `OFFICIAL` 里，没录入的公寓用历史参考价 + 示例优惠并标「示例数据」。「比较几个报价」：学生把拿到的报价（平台 / 官网 / 群里）填进来，按周租、合同周数、免租周、公寓立减、返现和到账条件、手续费，统一算成合同总价和真实每周价；指出「广告每周价是把一次性优惠平摊出来的」「返现要入住后才到账，拿不到时总价是多少」「要一次付清」；差价每周 £5 以内提示「差不多，先订房」；可一键复制结果交给专家。不公布任何平台价格。**开订提醒与订房资料卡**：关注公寓的房型和通知方式（专家群 / 小程序消息 / 邮件），开订时间是按公寓生成的示例数据，可模拟一次放房通知；订房资料卡提前填好护照拼音姓名、生日、入住日期、担保方式等，每项一键复制（不填护照号和银行卡号），附订房清单和进度；「开订当天」6 步流程和英国 / 北京时差，最后的提交和付款由学生自己点。数据存在 `lsm-quote-v1`、`lsm-ready-v1` |
| `mail-outbox.js` + `adviser/mail-panel.js` | 顾问后台「邮件提醒」：设置收件人和提醒类型，查看已发送的提醒和邮件预览。真实发送在 `web-original/consult-server`（`EMAIL_API_KEY`、`NOTIFY_EMAIL_TO`），邮件模板 `lib/email-template.js` 与演示预览共用 |
| `share-cards.js` / `.css` | 生活选房卡底部「生成分享卡片」：手绘地图 / 拍立得 / 车票 / 便利贴 4 种样式，1080×1350 竖图，二维码带分享人推广码 `?ref=`；可保存、系统分享或复制链接，手机上长按图片保存 |
| `adviser.html` + `adviser/` | 顾问后台（从提醒邮件点进来 `adviser.html#会话ID` 直接打开该学生；微信群码快过期时提示并可重新发送）：会话列表、学生上下文、建群并发送二维码、状态流转、数据看板，顶部可管理预建群池（`adviser/` 下的脚本复制自 `web-demo/`） |
| `demo-links.js` | 演示入口：地图右上角「i」说明里的「订房专家后台」「两端流程演示」链接，上线时删除 |
| `handoff-demo.html` | 两端流程演示：左边学生网站，右边顾问后台 |
| `sw.js` | 离线缓存，来自网页原版，文件清单改为本目录 |
| `photos/`、`vendor/qrcode.js` | 1 号公寓的房型照片（AmberStudent，2026-10-21）、二维码生成库 qrcode-generator 1.4.4（MIT） |

演示数据只存在浏览器本地（`lsm-live-me-v1` 学生会话、`lsm-live-admin-v1` 顾问后台、`lsm-live-pool-v1` 预建群池、`lsm-live-mail-v1` 提醒邮件记录），同一浏览器里的学生网站和顾问后台通过 storage 事件实时同步；二维码是演示链接，扫码不会进入真实群。其余 46 套公寓的房型按历史参考价列出，照片显示「照片整理中」，补照片时在 `room-photos.js` 的 `ROOMS` 里添加。

在线演示直达：链接末尾加 `#adviser` 打开订房专家后台，加 `#flow` 打开两端流程演示。

打开方式：在本目录运行 `python3 -m http.server`，访问 `http://localhost:8000/`（学生网站）、`/adviser.html`（顾问后台）、`/handoff-demo.html`（两端流程演示）。
