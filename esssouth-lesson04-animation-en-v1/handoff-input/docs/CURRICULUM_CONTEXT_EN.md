# Curriculum context

The planned series contains ten core lessons, each with an editorial allocation of approximately thirty minutes. The short preview and sample extracts are separate experience entries, not additional formal lessons. Watch and Practice are modes of the same lesson, not two separate lessons.

Current production sequence:

- L01: understand a shared discussion and ways to contribute.
- L02: make a view, reason and example clear, with appropriate limits.
- L03: listen closely, check meaning and make a connected response.
- L04: disagree constructively, compare alternatives and keep the next decision accurate.

Earlier curriculum notes placed these topics in a different order. Use the current L04 IDs and exact scope in this handoff; do not rebuild the earlier reasoning lesson under the old numbering.

Remaining curriculum coverage includes personal experience, prompt interpretation and a first contribution, handling disruptions to discussion, combining contributions into a shared proposal, transfer to unfamiliar tasks, and a continuous teaching simulation with review. Their detailed scripts and final order are outside this assignment. The current package asks only for L04.

All lessons use formal explanation with short character examples, meaningful authored interaction and editable language/timing. Neither the approximate series length nor the per-lesson budget is permission to add filler or claim a complete real assessment simulation.
