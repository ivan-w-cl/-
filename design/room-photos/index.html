What changes in the data

  • Each home gets a list of room types (name, weekly price, availability, private or shared kitchen and bathroom).
  • Each room type gets its own photos, tagged as bedroom, kitchen, bathroom or living area. Amber already tags them this way.
  • Building photos (courtyard, common room, gym) sit once on the home, below the room photos.
  • Fully booked room types stay visible but are marked, so students can still see what the place is like.

Which one?

  • A suits desktop: room type tabs and a big photo sit in the existing home panel, so nothing new opens over the map.
  • B suits phones: the sheet stays short, and the full album only opens when someone taps a room. On the real site, phones would get B and desktops A.
