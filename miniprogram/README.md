# 利物浦学生住宿地图 · 微信小程序（中 / 英）

原生小程序，界面和交互按网页版（`web-live/`）的手机布局 1:1 还原：同一张手绘地图、同样的颜色字体、同样的文案和数据。

## 进度

| 步骤 | 内容 | 状态 |
|---|---|---|
| 第一步 | 手绘地图（拖动、双指缩放、点选）、公寓卡片（简略 / 展开）、公寓列表（搜索、只看收藏、排序、前 3 名金色标签）、找公寓筛选（预算、房型、步行目的地、步行时间、图层开关）、中英切换、分享给朋友 | ✅ |
| 第二步 | 公寓详情和房型照片、一键进群（咨询编号、等群码、WhatsApp / 微信群码、群码到了推送提醒）、利物浦天气 | 进行中 |
| 第三步 | 生活选房、四个人格测试、结果卡、对比、分享卡片 | 待做 |

## 在微信开发者工具里打开

1. 导入本目录（含 `project.config.json` 的这一层）。`appid` 现在是游客模式占位 `touristappid`，换成你们的小程序 AppID 才能真机预览和上传。
2. 右上角「详情 → 本地设置」勾选 **不校验合法域名**（开发阶段连本机服务器）。
3. 另开终端运行服务器：`SITE_DIR=web-live node web-original/consult-server/server.js`（字体和以后的进群接口都从这里来，地址在 `config.js`）。
4. 编译即可。连不上服务器时也能用，只是字体会是系统字体。

上线前：在 `config.js` 填总部确认的 HTTPS 域名（需 ICP 备案），并在小程序后台「开发管理 → 服务器域名」登记 request 和 downloadFile 合法域名。

## 怎么做到和网页一样

- **地图**：`scripts/export-scene.cjs` 打开网页版，把地图上每一条路、每块绿地、每个图标、每个地名的最终坐标和样式导出成 `data/scene.js`，小程序用 Canvas 2D 按同样的顺序画出来（`map/render.js`）。放大后图标不再变大、文字有上限、重叠的标签自动隐藏，这些规则都照搬网页版。
- **数据和文案**：`scripts/export-data.cjs` 从网页版导出 47 处公寓、地点、教学楼、专业、排序方式和全部界面文案（`data/homes.js`、`data/web-strings.js`），筛选逻辑直接复用网页版的 `home-tools.js`。
- **字体**：网页用的 Google Fonts 在国内打不开。`scripts/build-fonts.cjs` 把手写字体精简（中文手写体从 1.5 MB 精简到约 150 KB，只留用到的字），放到 `web-live/fonts/`，由服务器提供，不占小程序包体积。
- **网页更新后同步**：`node scripts/sync-from-web.cjs`（需要先在 `web-live` 起一个静态服务器 8769 端口，见脚本注释）。

## 目录

```
app.js / app.json / app.wxss   全局：语言、存储、字体、颜色变量
config.js                      服务器地址（开发 / 上线）
pages/index/                   首页：地图、卡片、公寓列表、找公寓
map/render.js                  手绘地图渲染器（小程序和浏览器共用）
map/view.js                    视角：全图、对准公寓区、平移、缩放上下限
utils/                         文案、公寓筛选排序、字体、home-tools.js（网页版原文件）
data/                          【自动生成】地图场景、公寓数据、网页文案
scripts/                       从网页版导出数据、地图、字体
tools/                         开发用：浏览器里的地图预览、小程序页面预览（截图检查用，不打包）
server-fonts/                  字体原文件（不打包）
```

`tools/wx-preview.cjs` 只是在浏览器里近似模拟页面，方便截图检查；最终效果以微信开发者工具和真机为准。
