# 验收清单

交付前逐条核对。打不了勾的，要么修，要么在交付说明里写明。

## 内容

- [ ] 选题能写成一句话问题，全片只讲这一个问题。
- [ ] 去掉产品中插，科普仍然完整、有用。
- [ ] 开场直接进入具体现象或事实，没有泛泛的套话，没有虚构的亲身经历。
- [ ] 结尾是知识结论，不是宣传口号。
- [ ] 全片没有二维码、关注、购买、加客服、咨询等号召。
- [ ] 默认观众不了解英国地理、气候、大学分布和租住习惯，专有名词有解释。

## 事实

- [ ] 每条事实在 `SOURCES.md` 里有来源链接、地区、统计时段和核对日期。
- [ ] 优先用了官方原始资料。
- [ ] 用区域数据代替当地数据的地方，画面上写明了区域和时段。
- [ ] 计算所得的数字标了「计算所得」，算法可复核。
- [ ] 没有「最准确」「保证」「绝对」这类无法支持的承诺。
- [ ] 涉及新闻时，分别确认了事件日期、报道日期和核对日期。
- [ ] 示意地图、示例数字、几何示意图在画面上有标注。

## 产品中插

- [ ] 约 20 秒，集中在视频中段，只展示一项和本期话题直接相关的功能。
- [ ] 第一句让观众明确知道是在介绍我们的工具。
- [ ] 所有点击、拖动、切换和结果变化来自真实界面，没有虚构的按钮、数据或结果。
- [ ] 说清了具体便利，也说清了功能边界，和工具界面上的原文一致。
- [ ] 界面保留真实中文，没有伪造英文界面。
- [ ] 产品名和描述用法正确，没有自造英文品牌名。
- [ ] 中插之后回到科普，没有继续展开其他功能。

## 画面

- [ ] 1080×1920，30fps。
- [ ] 画面随讲解变化，没有连续几秒空着不动的画面。
- [ ] 文字在手机上读得清，没有重叠、裁切或跑出画面。
- [ ] 字幕没有挡住关键操作；字幕断句自然。
- [ ] 科普段没有常驻 Logo，没有反复露出品牌。
- [ ] 草稿联系表逐张看过，录制日志里没有「找不到元素」的警告。

## 声音

- [ ] 配音自然清晰，语速 1.25 倍，没有夸张的广告腔。
- [ ] 背景音乐轻快，音量明显低于人声；点击音效适量。
- [ ] 音乐来源和授权在 `SOURCES.md` 里写明。
- [ ] 如果没能用耳朵试听，在交付说明里写明并请用户试听。

## 交付

- [ ] 完整成片、无音乐版、无字幕干净画面版、人声独立音轨、音乐加音效底轨。
- [ ] 旁白全文、两份 SRT、分场景时间表、`SOURCES.md`。
- [ ] 可编辑工程：画面文字在 `TXT` 表里，旁白在 `script.json` 里，能按说明重新生成。
- [ ] 交付说明如实列出：已核实的、没能核实的、需要用户确认的。
