# 升学科普视频 demo · 综评到底多给了考生什么机会？

面向江苏、广东的高中学生和家长，竖屏 1080×1920、30 fps，约 2 分钟。

## 交付物

| 文件 | 说明 |
|---|---|
| `out/综评到底多给了考生什么机会-配乐.mp4` | 有背景音乐，无配音（字幕在画面里） |
| `out/综评到底多给了考生什么机会-无配乐.mp4` | 无背景音乐、无配音（带一条静音音轨，方便剪辑软件识别） |
| `out/综评到底多给了考生什么机会.srt` | SRT 字幕，和画面字幕同一时间轴 |
| `out/配音时间轴.json` | 每行旁白的起止时间。换成真实配音后可以重新对齐 |
| `out/图文/封面.png`、`总结图-1…6.png` | 1080×1440 的封面和 6 张总结图 |
| `docs/配套文案.md` | 约 570 字配套文案，和总结图分开 |
| `docs/分镜与配音稿.md` | 创作方向、分镜表（含政策依据、是否用产品、为什么用、看完能明白什么）、逐行配音稿 |
| `docs/政策来源.md` | 来源链接、年份、省份、适用项目、本次核对结果，以及官方规定、假设算例、作者建议三类内容的区分 |
| `video.html` `script.js` `cards.html` | 可以继续修改的项目源文件：动画、文案、图文卡片 |
| `capture/` | 三段真实产品画面的原始截图序列，以及每次点击的位置 |
| `tools/` | 截图、导出、生成背景音乐、配音对齐与混音、生成文档的脚本 |

## 配音（本版缺项）
按要求先不使用火山引擎，**这一版没有配音**。指定声音是 `zh_male_wenrouxiaoge_uranus_bigtts`，speech_rate 25。我没有换用任何其他声音。

补配音的步骤：
1. 按 `docs/分镜与配音稿.md` 逐行录制，文件名用行号，例如 `voice/S01L1.wav`。
2. 运行 `node tools/set-voice.cjs`，量出每行的实际时长。
3. 运行 `node tools/export.cjs`，画面和字幕会按真实时长重新排布。
4. 运行 `sh tools/mix-voice.sh`，生成"配音 + 配乐"和"配音、无配乐"两个版本。

配音脚本用测试音频验证过能跑通，没有用真实配音测过。

## 产品画面说明
三段产品画面都是在真实页面上操作、逐帧截图得到的，视频只加了点击圈和局部放大，没有绘制或改动任何界面：
1. **考情导学 · 计算器**（西浦 · 江苏）：输入两组假设分数，显示 83.50 和 77.80。
2. **考情导学 · 切换省份**：江苏切到广东，要点速记里的比例、报名时间随之变化。
3. **5 分钟练习 · 观点加理由**：团队预览网站，使用演示学生账号。先只写观点，提示缺理由；补上 because 后显示"做到了"。页面上原本就写着"演示：关键词规则，不是 AI，也不是评分"。

这些页面都是网页测试版，不是小程序或 iOS 正式版。视频底部标签写的是"esssouth 网页测试版 · 真实界面录制 · 演示账号与示例数据"。**小程序、iOS 的录屏这次没有素材**，如需要请提供。

## 背景音乐
`assets/bgm.wav` 由 `tools/bgm.py` 现场生成（原创的轻快拨弦加铺底），不涉及第三方版权，可以替换成团队自己的配乐。

## 重新生成
```
python3 tools/bgm.py 125          # 背景音乐
node tools/capture.cjs            # 重新截产品画面（需要先在 8851 端口启动团队预览网站）
node tools/export.cjs             # 导出 MP4、SRT、时间轴
node tools/cards.cjs              # 封面和总结图
node tools/docs.cjs               # 分镜与配音稿
```
需要 Node 18+、Playwright（Chromium）、ffmpeg 和 Python 3。
