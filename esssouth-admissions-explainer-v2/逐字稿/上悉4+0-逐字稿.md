**0:04　上悉 4+0，是什么、考什么？**

画面文字：
- 上悉 4+0，是什么、考什么？
- 高考达本科线
- 学院笔试
- 面试

讲解：
1. 这一集讲上海大学悉尼工商学院的悉尼科技大学学士学位项目，也就是常说的「4+0」。
2. 先说清楚：它不是综合评价招生，而是高考成绩达标后，参加学院自己组织的入学考试和面试。
3. 下面的内容依据学院官网的 2026 年招生简章。

**0:28　4+0 读的是什么**（项目基本信息（2026））

画面文字：
- 四年在上海读完：毕业获悉尼科技大学（UTS）学士学位
- 学位可认证：可在教育部留学服务中心进行学历学位认证
- 金融学 80 名：直接进入金融学专业，第三年专业分流
- 国际经济与贸易 / 工商管理 170 名：前两年不分专业，第三年双向选择
- 两年后也可出国完成：国外大学多个本科专业可选

讲解：
1. 4+0 的意思是：四年都在上海就读，毕业获得悉尼科技大学的学士学位，可以在教育部留学服务中心做学历学位认证。
2. 2026 年计划招 250 人：金融学 80 人；国际经济与贸易和工商管理，也就是经管类方向，170 人，前两年不分专业，第三年分流。
3. 读满两年后，也可以选择去国外完成学士学位。

### 第 2 集 · 怎么报名（0:59 起）

**0:59　开场提问**（三位同学围坐，阿杰提问）

- 阿杰：我能报名吗？流程是怎样的？

**1:04　谁可以报**（报名条件）

画面文字：
- 参加 2026 年高考的应届高三生：国内全日制普通高中，不含同等学力
- 高考总分 ≥ 当地本科控制线：不含独立本科线
- 报金融学：数学单科 ≥ 105：满分 150
- 不参加高考？：只能报考学院 IUP 项目，不能报 4+0

讲解：
1. 报名条件有三条。第一，是参加 2026 年高考的国内全日制普通高中应届高三学生，不含同等学力。
2. 第二，高考成绩公布后报考的，高考总分要达到当地本科控制线，不含独立本科线。
3. 第三，如果报金融学，高考数学单科还要不低于 105 分，满分 150 分。
4. 不参加高考，或者只有国外高中毕业证书的同学，只能报考学院的 IUP 项目，不能报 4+0。

**1:40　从注册到入学**（简章里的报考流程）

画面文字：
- 1. 注册 + 完善信息：silcadmission.shu.edu.cn（信息审核）
- 2. 选考位 + 缴费：报名费 1,200 元（报名时间见官网通知）
- 3. 参加笔试：英语（含口试）、语文、数学（每人每年只能考一次）
- 4. 笔试过线 → 面试：面试成绩计入总分
- 5. 录取 + 入学审查：达线发拟录取通知（缴学费，入学资格审查）

讲解：
1. 报考流程是这样的：先在学院的招生系统注册，完善报名信息，等待审核。
2. 审核通过后选择考位，缴纳 1200 元报名费。具体报名时间，以学院官网的后续通知为准。
3. 然后参加笔试。注意，每位考生每年只能参加一次入学考试。
4. 笔试成绩过了面试资格线，才能参加面试，面试成绩计入总分。
5. 面试后学院公布录取分数线，达线的直接发拟录取通知；缴纳第一学年学费后，进入入学资格审查。

3. 面试成绩计入总分。
4. 面试后公布录取分数线，达到分数线的考生，直接发放拟录取通知书。

### 第 5 集 · 考前准备什么（3:50 起）

**3:50　开场提问**（三位同学围坐，阿杰提问）

- 阿杰：考前要注意什么？

**3:54　三件事**（考前准备）

画面文字：
- 高考：总分过本科线：报金融学的，数学至少 105
- 笔试：英语 + 语文 + 数学：高中知识，别在高考后完全放下
- 口试和面试：英语表达：观点 + 理由 + 例子
- 只有一次机会：每人每年只能参加一次入学考试

讲解：
1. 准备上悉，要同时顾好三件事。第一，高考总分过当地本科控制线；报金融学的，数学至少 105 分。
2. 第二，学院笔试考英语、高中语文和高中数学，高考后不要完全放下。
3. 第三，英语口试和面试，要练习用英语完整地表达观点、理由和例子。
4. 还有一点：每人每年只能参加一次入学考试，要把握好。
