# esssouth — complete Lesson 08 animation handoff

**Bring Contributions Together into a Shared Proposal** is one proposed seven-section training lesson. This package contains exact English scripts, labels, semantic anchors, explicit holds, choice/private-rehearsal contracts, retime fixtures and an unchanged historical animation reference. It does not contain a newly produced Lesson 08 animation, narration or video.

Send this ZIP and paste COPY_PASTE_PROMPT_EN.md. The recipient can implement all seven sections in order without a separate prompt per section.

- START_HERE_FOR_CLAUDE.md gives reading order and scope.
- LESSON08_OVERVIEW_EN.md shows progression, budgets and transparent estimates.
- LESSON08_ALL_SECTIONS_EN.md collects exact script and staging.
- sections/S01–S07/ contains authoritative graph, labels, timings, anchors, empty audio slots, retime fixture, routes and readable brief.
- content/ contains fixed main and transfer cases and the full outline.
- docs/ contains style, case evidence, modes, production and acceptance requirements.
- reference-l02-s04/ is historical style source/player, not a new general compiler or a new test result.
- tools/validate-authoring.py is an independent input-integrity audit.
- BUILD_STATUS_TEMPLATE.json distinguishes implementation from script readiness.
- REFERENCE_PROVENANCE.json and HANDOFF_MANIFEST.json identify source and delivered bytes.

All scenarios are fictional general communication training. No actual learner data, official scoring rubric, credentials or deployment is included. Keep earlier projects and the reference unchanged. Later real narration and any localized explanation are separate work.
